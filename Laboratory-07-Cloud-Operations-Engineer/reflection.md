Monitoring the host server's resources is important even when containers appear to be running perfectly because containers ultimately share the host machine's CPU, memory, storage, and network resources. 
A container may show a healthy status while the server itself is experiencing high resource consumption, low disk space, or memory exhaustion, which can eventually lead to slow performance, application failures, or unexpected downtime. 
By regularly monitoring host resources, cloud engineers can identify potential bottlenecks before they affect users and ensure that the system remains stable and responsive. When troubleshooting application issues, commands such as `docker logs` are extremely valuable. 
For example, if a user reports that they cannot log into a web application, reviewing the container logs can reveal authentication errors, database connection failures, invalid credentials, missing environment variables, or application exceptions that occurred during the login process. 
Instead of guessing the cause of the problem, engineers can use log messages to locate the exact error and resolve it more quickly. Logs and metrics, however, serve different purposes. Logs are detailed records of specific events and actions occurring within an application, such as user logins, errors, warnings, and system messages. 
Metrics, on the other hand, are numerical measurements that provide an overview of system performance, such as CPU usage, memory consumption, disk utilization, response times, and network traffic. Large enterprise organizations often monitor thousands of containers simultaneously using specialized monitoring platforms such as Prometheus and Grafana.
Prometheus automatically collects metrics from containers and infrastructure components, while Grafana visualizes those metrics through dashboards and alerts. Together, these tools allow operations teams to detect issues, analyze trends, receive notifications about abnormal behavior, and maintain reliable performance across large-scale containerized environments.

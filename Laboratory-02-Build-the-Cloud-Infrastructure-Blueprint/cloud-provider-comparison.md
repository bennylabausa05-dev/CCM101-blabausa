## 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers one of the broadest ranges of cloud services. It provides many options for computing, storage, databases, networking, security, AI, and other cloud needs.
## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
I would recommend Microsoft Azure for an organization that mainly uses Microsoft products. Azure works well with services such as Windows Server, Microsoft 365, and other Microsoft technologies, making integration easier.
## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for its AI and machine learning services. It is also well known for Kubernetes because Google originally developed Kubernetes.
## 4. What similarities did you observe among the three cloud providers?
All three providers offer similar basic cloud services, such as compute, storage, networking, and identity and access management. The main difference is the names, features, and tools they use for each service.

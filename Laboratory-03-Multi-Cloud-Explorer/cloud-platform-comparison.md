## Follow Up Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services. It has been in the market the longest, starting in 2006, so it has had more time to build out compute, storage, database, analytics, and AI services than the other two providers.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure integrates best with Microsoft technologies. Since Microsoft also builds Windows Server, Active Directory, and Microsoft 365, Azure is designed to work smoothly with these products, especially through services like Microsoft Entra ID.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is generally considered the strongest in AI and Kubernetes. Google created Kubernetes and runs GKE, one of the most mature managed Kubernetes services, and its Vertex AI platform is built on Google's own AI research.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS for most general-purpose projects because it has the widest service catalog and the most learning resources and community support, which makes it easier to find solutions when I run into problems. That said, the "best" choice really depends on the specific project — a Microsoft-heavy company would benefit more from Azure, and an AI-focused team would benefit more from GCP.

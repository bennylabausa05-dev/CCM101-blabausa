### Bash Script: What is it, and what does the #!/bin/bash line (the shebang) do at the top of a file? 
A Bash script is a text file with a list of commands that the computer runs one after another, so you don’t have to type them by hand. 
The first line, `#!/bin/bash` (the shebang), tells the system to run the file using Bash.

### Variables: Why do programmers use variables (like $BACKUP_DIR) instead of typing out the exact folder path every time? 
A variable stores a value, like a folder path, under a name such as $BACKUP_DIR. If the path changes, you fix it in one place instead of everywhere, and you make fewer typing mistakes.

### Cron Job: What is a cron job in Linux, and why is it essential for cloud operations?
A cron job is a task that Linux runs automatically at a set time, like a backup every night at 2 AM. 
It is essential in cloud operations because servers need routine jobs done on time and without a person doing them.
